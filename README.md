# 毛球屋 · 养宠成长记录与社区

Vibe Coding 题目「养宠成长记录与社区」的可运行实现：记录体重 / 疫苗 / 驱虫等健康数据、生成成长时间线、按地域匹配宠友、分享养宠日常。设计稿、用户原声调研和闭环链路图见配套的设计画布。

> 演示版：数据只保存在浏览器本地（localStorage），圈子里的宠友、求助、帖子是模拟数据；所有健康相关内容仅供参考，不能替代兽医诊断。

## 快速开始

```bash
npm install
npm run dev      # 本地开发，打开终端里提示的地址（建议用手机尺寸查看）
npm run check    # 类型检查 + 44 个测试 + 生产构建
npm run build    # 产物在 dist/，可直接放到任意静态托管
```

需要 Node.js 18 及以上（开发与测试使用 Node 22）。

## 功能与闭环

每个功能都从「触发」回到「下一次触发」：

| 功能 | 闭环 | 代码 |
|---|---|---|
| 3 步建档 | 物种 → 名字 → 形象 → 入住「家」；生日、绝育等第一周通过宠物头顶的「?」慢慢补 | `pages/Onboarding.tsx` |
| 「XX的家」 | 宠物用姿势表达今天的状态（开心 / 平静 / 不舒服）；房间里的秤、药箱、挂历、小门、相框就是入口，挂牌平时只显示名字，有事才变色说话（「该称啦」「剩 2 天」） | `components/Scene.tsx` |
| 每日一问 → 晴雨计 | 一天一次；「都挺好」一键完成，不对劲才多选；奖励与回答内容无关；变差时引导状态检测 | `components/DailySheet.tsx`、`domain/weather.ts` |
| 护盾（驱虫 / 疫苗） | 平时只显示「安全」，进入提醒期才倒计时；打卡时点选实际日期，下次到期 = 实际日期 + 周期；只奖励按时，不奖励多做 | `domain/shield.ts`、`components/CompleteSheet.tsx` |
| 称重小游戏 | 直接称或抱着称自动相减；曲线叠加兽医建议区间；近 4 周变化超过 5% 温和提示咨询兽医；连续按时称重成就 | `domain/weight.ts`、`components/WeighSheet.tsx` |
| 计划模板 | 物种、年龄阶段从档案带入；勾选项目 → 上次时间 → 产品类型 → 预览生成；已有记录可沿用 | `domain/planTemplate.ts`、`pages/PlanWizard.tsx` |
| 状态检测 → 就诊 | 先排除急症（红旗）→ 点身体图选部位 → 症状与时长 → 分级 → 一键就诊摘要（复制链接 / 二维码 / 存图片）→ 就诊回填自动生成用药与复诊提醒 | `domain/triage.ts`、`domain/summary.ts`、`pages/CheckFlow.tsx` |
| 成长时间线 | 每日一问、护盾、称重、就诊、日常、遛狗局自动汇入；到家 N 天与生日自动成为里程碑；每条记录显示操作人；宠物详情只有「成长 / 档案」两个分页，顶部摘要卡跳到养护 | `pages/PetDetail.tsx`、`domain/milestones.ts` |
| 分享卡片 | 成长纪念 / 月度报告 / 体重曲线三种模板；3:4 导出；自动隐藏芯片号与精确位置；带「来串门」二维码 | `components/ShareComposer.tsx` |
| 圈子 | 顶部 Tab：推荐 · 附近 · 宠友 · 同好，默认推荐；遛狗局 / 串门 / 寻宠 / 托付四个图标入口；附近求助置顶；双列瀑布流；带档案提问；送小鱼干每天有上限 | `pages/CirclePage.tsx` |
| 遛狗局（狗） | 顶部 Tab「找局 / 组局」；过滤（3 公里、疫苗、发情期、体型、满员）+ 排序（时段 40% / 氛围 30% / 距离 20% / 规模 10%）→ 加入 → 到场打卡 → 评价 → 一起遛过的人成为宠友；只在公共地点、多人，不做一对一 | `domain/match.ts`、`pages/WalkPage.tsx` |
| 云串门（猫） | 逛别人家的公开视图、送小鱼干；互相串门成为宠友 | `pages/VisitPage.tsx` |
| 走失求助 | 从档案生成寻宠卡推送 1 公里；邻居「我看到了」站内发线索；可扩大到 3 公里；找回后下架 | `pages/LostPage.tsx` |

| 家庭共养 | 切换当前家人，每条记录都带操作人，避免重复喂药 | `pages/MePage.tsx` |

## 设计规范在代码里的落地

- **色板**：从生成插画里取色校准（描边藏青 `#082C5C`、主操作橘 `#FC9A59`、晴空蓝 `#75BFF1`、薄荷绿 `#90D6AB`），见 `src/styles/app.css` 顶部变量。
- **颜色语义**：橘色只用于主操作和奖励；选中态是晴空蓝浅底 + 勾号；珊瑚红只用于逾期、需就医和走失。
- **描边三级**：2px 藏青只给宠物插画、主按钮、＋按钮；卡片和选项无描边（浅底 + 轻阴影）；诊室模式用 1px 细线。
- **可见范围三档**：仅家人（默认，健康记录固定在这一档）/ 宠友 / 公开；公开内容才进入推荐与同好，位置只到街区。
- **入口分工**：每种数据只有一个「家」——今天的事在「家」，健康数据与计划在「养护」，成长与档案在「宠物详情」，社交在「圈子」。
- **两种语气**：家、成就、分享卡用奶油底贴纸风；状态检测、计划模板、就诊摘要用冷白底的诊室模式，严重时不再用天气隐喻，直接说「建议尽快就医」。
- **无障碍**：触控区域不小于 44px；图标按钮都有 `aria-label`；选项用 `aria-pressed`；弹层可用 Esc 关闭；尊重「减少动态效果」系统设置。

## 规则默认值（都可调整）

- 晴雨计计分：满分 100，按例外扣分（没精神 −25、少吃 −20、不吃 −45、软便 −10、腹泻 −30、呕吐 −25、护盾逾期 −10、体重变化明显 −15，见 `domain/weather.ts`），≥85 晴、65–84 多云、40–64 小雨、<40 或任一红旗为需就医。
- 护盾提醒期：每周 1 天、月度 3 天、季度 7 天、年度 14 天（「我的 → 提醒」可改月度和年度）。
- 计划模板周期为常见默认值（`domain/planTemplate.ts`），界面始终注明以兽医医嘱为准。

## 项目结构

```
src/
  domain/      纯函数：日期、护盾、晴雨计、体重、分诊、计划模板、里程碑、匹配、geohash、就诊摘要
  store/       状态：演示数据、reducer（所有闭环动作）、选择器、上下文与本地持久化
  components/  通用组件：基础 UI、底栏、快捷面板、场景、各类弹层、分享卡、二维码
  pages/       页面：家、养护、计划、检测、宠物详情、圈子、约遛、串门、走失、托付、我的、建档
  styles/      样式与设计变量
public/assets/ 51 个处理过的插画素材与图标（透明底 WebP，已去地面阴影、已切分）
tests/         领域单测、reducer 闭环测试、页面集成测试（Vitest + Testing Library + jsdom）
```

## 测试

`npm test` 运行 44 个测试：

- `tests/domain.test.ts`：日期、护盾状态与奖励、晴雨计、体重趋势、分诊、计划模板、里程碑、geohash 与匹配、就诊摘要。
- `tests/reducer.test.ts`：每日一问、护盾打卡、称重、就诊回填、约遛、走失、送小鱼干、托付等闭环。
- `tests/app.test.tsx`：在页面上点完整流程，包括每日一问、打卡、抱宠称重、计划生成、状态检测两条路径、分享卡、约遛、走失线索、带档案提问、3 步建档。

## 部署到 GitHub Pages

仓库已带 `.github/workflows/pages.yml`：在仓库 Settings → Pages 把 Source 设为「GitHub Actions」，推送到 `main` 后会自动检查并发布。`ci.yml` 会在每次推送时跑完整检查。

## 已知限制与下一步

- 没有后端：就诊摘要的分享链接只在同一设备上有效；圈子、约遛、托付中的其他用户是模拟数据。
- 站酷快乐体（SIL OFL 开源可商用）已按项目里用到的 897 个字裁成 91 KB 的子集打包；用户自己输入的生僻名字会回退到系统字体。
- 底部导航、快捷面板、护盾和晴雨计都已换成插画图标（底栏选中为彩色、未选中变灰）；返回、关闭、搜索这类功能小符号保留矢量线条并加粗，保证小尺寸清晰。
